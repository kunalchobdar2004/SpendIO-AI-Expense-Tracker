# SpendIO - AI-Powered Expense Tracker 🚀

SpendIO is a modern, intelligent full-stack SaaS application that helps users track, manage, and analyze their expenses using the power of Google Gemini AI.

## ✨ Key Features
- **📸 AI Receipt Scanner:** Upload a picture of any bill, and the Gemini AI Vision model automatically extracts the amount and category.
- **🤖 Smart AI Advisor:** Chat directly with your financial data. Ask questions like "Where did I spend the most this month?" and get personalized answers.
- **📊 Visual Dashboards:** Beautiful, interactive Pie Charts using Recharts to visualize spending categories.
- **📥 One-Click Export:** Download all your transaction history instantly in CSV format.
- **📱 Responsive UI:** Clean, modern, and mobile-friendly interface built with React and Tailwind CSS.
- **🔐 Secure Authentication:** Full user signup/login system with profile picture upload functionality.

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS, Recharts, React Router
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **AI Integration:** Google Gemini (1.5 Flash / 2.0) via direct fetch API
